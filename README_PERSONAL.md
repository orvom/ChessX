# ChessX - COMPLETE personal copy

This folder is a full, ready-to-run copy of the project for PERSONAL use only.

- `ChessX.exe`      - double-click to run (Python not needed). Everything is bundled inside.
- `ChessX.bat`      - runs from source instead (needs Python + `pip install -r requirements.txt`).
- `server.py`, `index.html`  - the app (backend + UI).
- `stockfish/stockfish.exe`  - Stockfish 19 engine (GPL-3.0).
- `pieces/`         - ALL 52 piece sets (16 redistributable + 36 personal-use only).
- `data/`           - opening database (CC0).
- `scripts/`        - get_stockfish.py, get_pieces.py, build_exe.py.
- `README.md`, `LICENSE`, `THIRD_PARTY.md` - docs and licenses.

IMPORTANT: this folder (and the ChessX.exe in it) contains piece sets that are CC BY-NC-SA, "personal use only"
or have no stated license. Do NOT upload this whole folder to a public GitHub repo or share the exe.
For a public repo use the `ChessX` project folder (git repo) instead; see THIRD_PARTY.md.
